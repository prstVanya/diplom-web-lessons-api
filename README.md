## Установка проекта
Клонирование проекта SSH:
```sh
$ git clone git@github.com:prstggvv/diplom-web-lessons-api.git
```

Установка зависимостей:
```sh
$ npm i
```
___

## Запуск проекта
Запуск проекта:
```sh
npm run start
```
